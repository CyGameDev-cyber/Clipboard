# Clipboard
This is a simple educational project that demonstrates how clipboard jacking works. Attackers can replace copied text (like crypto wallet addresses) with their own. 

⚠️ Educational only – do not use maliciously.

🚀 Features

📋 Copy a sample BTC address

🎭 Toggle attack simulation on/off

📝 Paste into the text box to compare results

🧹 Clear Log and Input separately


📖 Usage

Open 👉 [Live Demo](https://cygamedev-cyber.github.io/Clipboard/) in your browser

Click Copy Sample BTC Address

Turn attack ON/OFF

Paste into the text area to see what happens
